# Mid Term Projects

These advanced projects demonstrate real-world applications of machine learning and deep learning in critical domains. Each project is thesis-ready and showcases professional-level implementation.

## Projects Overview

### 1. Breast Cancer Detection (APANAC + Tesis)
Deep learning for breast cancer classification with deployment-ready Gradio application.

### 2. Chest X-Ray Analysis
Radiology AI for automated chest X-ray interpretation and diagnosis.

### 3. Medical Image Segmentation (APANAC + Tesis)
Advanced image segmentation for cell nuclei and medical imaging applications.

### 4. Self-Driving Car Vision
Behavioral cloning for autonomous vehicle steering prediction.

## Important Notice

**Projects with "APANAC + Tesis" suffix cannot be:**
- Used as a thesis topic (already reserved)
- Presented at JIC (Jornada de Investigación Científica)
- Presented at APANAC events

These restrictions exist because these projects are already committed to specific research initiatives.

## Project Characteristics

All mid-term projects feature:
- **Real-World Impact**: Solving actual problems in healthcare or autonomous systems
- **Advanced Techniques**: State-of-the-art deep learning architectures
- **Complete Implementation**: From data processing to deployment
- **Professional Quality**: Thesis-ready code and documentation
- **Deployment Options**: Web apps, APIs, or real-time systems

## Getting Started

Each project folder contains:
- Detailed README with setup instructions
- Jupyter notebooks with complete workflows
- Trained models or training scripts
- Deployment code (where applicable)

Navigate to individual project folders for specific instructions.
