## Getting Started

1. **Prerequisites**: Start with the `Prerequisitos` folder to ensure you have the foundational knowledge
2. **Environment Setup**: Most projects include `requirements.txt` for dependency installation
   ```bash
   pip install -r requirements.txt
   ```
3. **Choose Your Path**: Progress through ProyectosEnClase sequentially or jump to topics of interest
4. **Labs**: Complete laboratory assignments to reinforce learning

## Course Learning Path

```
Prerequisites → Traditional ML → Computer Vision → Optimization → LLM/AI Applications
```

1. Master Python and data science libraries
2. Learn classification, regression, and clustering
3. Explore computer vision with YOLO
4. Dive into optimization techniques
5. Build modern AI applications with LLMs and agents
