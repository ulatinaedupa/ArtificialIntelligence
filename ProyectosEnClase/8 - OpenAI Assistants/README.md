# Project 8: OpenAI Assistants & DALL-E 3

## Overview
Create automated presentation generation using OpenAI's GPT models and DALL-E 3 for image creation. This project demonstrates the power of combining language models with image generation.

## Project Structure
```
8 - OpenAI Assistants/
├── Creando Presentaciones con OpenAI y DALLE-3.ipynb  # Main notebook
├── data/                                               # Generated content
└── imgs/                                               # DALL-E generated images
```

## Learning Objectives
- Working with OpenAI API
- GPT-4 for content generation
- DALL-E 3 for image creation
- Automated workflow creation
- Combining text and visual AI
- Prompt engineering

## Getting Started

### Prerequisites
```bash
pip install openai python-pptx pillow
```

### API Setup
1. Get OpenAI API key from https://platform.openai.com/
2. Set environment variable:
```bash
export OPENAI_API_KEY='your-api-key-here'
```

### How to Run
```bash
jupyter notebook "Creando Presentaciones con OpenAI y DALLE-3.ipynb"
```
