# Project 12: Google Gemini Integration

## Overview
Explore Google's Gemini AI models for multi-modal applications including text, image, and code generation. Learn to integrate Gemini's powerful capabilities into your applications.

## Learning Objectives
- Google Gemini API integration
- Multi-modal AI applications
- Vision and language tasks
- Code generation with Gemini
- Prompt engineering for Gemini
- Comparing LLM providers

## Getting Started

### Prerequisites
```bash
pip install google-generativeai pillow
```

### API Setup
1. Get API key from Google AI Studio
2. Set environment variable:
```bash
export GOOGLE_API_KEY='your-api-key-here'
```

### How to Run
```bash
jupyter notebook  # Open notebooks in this directory
```
