# Project 0: Console Game Development Analysis

## Overview
An introductory data analysis project exploring console game development data. This project serves as a gentle introduction to data analysis techniques in the context of the gaming industry.

## Project Structure
- **Workshop Notebook**: Main Jupyter notebook for data analysis
- **Dataset**: `1_workshop_data.csv` - Console game development data
- **Documentation**: Supporting materials and references

## Learning Objectives
- Introduction to Jupyter notebooks
- Basic data exploration and visualization
- Understanding data analysis workflows
- Working with CSV datasets

## Getting Started

### Prerequisites
- Python 3.x
- Jupyter Notebook
- Pandas, NumPy, Matplotlib

### How to Run
1. Open the Jupyter notebook in the project directory
2. Run cells sequentially to perform the analysis
3. Explore the dataset and modify visualizations as needed

## Key Concepts
- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization techniques
- Drawing insights from gaming industry data

## Dataset
The workshop dataset contains information about console game development, providing a real-world context for learning data analysis fundamentals.
