# Lab 0: Introduction to Machine Learning Fundamentals

## Overview
Introductory laboratory focusing on the fundamentals of machine learning. This lab provides hands-on experience with basic ML concepts, data manipulation, and your first predictive models.

## Project Structure
```
Lab0/
├── Lab0.ipynb        # Main laboratory notebook
└── datasets/         # Practice datasets
```

## Learning Objectives
- Understand core ML concepts
- Load and explore datasets
- Perform basic data preprocessing
- Train your first ML models
- Evaluate model performance
- Visualize results

## Getting Started

### Prerequisites
```bash
pip install pandas numpy matplotlib scikit-learn jupyter
```

### How to Run
```bash
jupyter notebook Lab0.ipynb
```

## Key Concepts Covered
- **Machine Learning Basics**: Supervised vs unsupervised learning
- **Data Loading**: Reading datasets with Pandas
- **Exploratory Data Analysis**: Understanding your data
- **Data Preprocessing**: Cleaning and preparing data
- **Model Training**: First ML algorithms
- **Evaluation**: Assessing model performance

## Topics
1. Introduction to ML workflows
2. Data loading and inspection
3. Feature exploration
4. Train/test split
5. Model training (linear models, decision trees)
6. Making predictions
7. Evaluating accuracy

## Datasets
Practice datasets are provided in the `datasets/` directory covering various ML scenarios.

## Expected Outcomes
By completing this lab, you will:
- Understand the ML development cycle
- Be comfortable with Jupyter notebooks
- Know how to load and explore data
- Train and evaluate basic models
- Interpret model results
